# Portfolio Website

Lab 2 – JavaScript for Web Development, Högskolan Kristianstad (HT26)

Target Grade = 3

## Description

A personal portfolio website with a new added link to feedback form for user input built with HTML, CSS and JavaScript. Aiming to meet criterias for level 3 grade track.

## Features

- Feedback form including five input fields: Full name, email, topic, message and website.
- Field validation showing clear error messages.
- Required and optional fields, including specific input requirements.
- Form showing visual states for neutral, error or valid input.
- Live character counter for message input.
- Success message for user. Clearing after 4 seconds per assignment requirement.
- Submit and Clear button.
- No data is sent or stored.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git

## How to run

Clone the repository: `git clone https://github.com/jenslahti/portfolio-website.git`
Open `index.html` in a browser.
Click "Send Feedback" on the homepage. Located in the navigation bar, top right corner. Form opens in a new tab.
